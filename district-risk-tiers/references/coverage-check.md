# Coverage check

Before you compute, list each group the document names and the indicators in the vulnerability score that describe that group. A group with no indicator is a gap.

| Group named in the document | Indicators in the score | Covered? | Action |
|---|---|---|---|
| Children under five | stunting, wasting, underweight (survey, district) | Yes | none |
| Mothers and pregnant women | none | No | Add maternal indicators (for example thin women, women's anaemia, teenage motherhood, antenatal care, iron-folic acid, women's schooling), or narrow the claim to children |
| [group] | [indicators] | [yes / no] | [action] |

Rules:
- A score may be called "children and mothers" only if it has indicators for both.
- If you add a second score for the missing group, say whether it enters the risk score. Merging it later is a rule change and a deviation, because tiers can move.
- Show both scores side by side (a bivariate map of the two vulnerability tiers works well) and say which one the risk score uses.
- A tribal or caste share can sit in the score as a social vulnerability marker. Say that it is a choice and who made it.
- Note where an indicator comes from a different survey round or a different boundary. Say so in the limits list.
