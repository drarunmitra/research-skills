# Frameworks: what to use and when

Verdict: core = build in. optional = use when the case needs it. No framework here has a trial showing it improves decisions. They are expert consensus.

| Framework | Use for | Verdict |
|---|---|---|
| SUPPORT tools and SURE guides (problem, options, implementation, with quality, applicability, equity) | The spine of any brief | core |
| WHO EVIPNet and McMaster evidence brief (key messages, problem, three options, implementation, front matter) | Structure and disclosures. Change its "no recommendations" rule: add one labelled recommendation | core |
| CHSRF 1:3:25 (one page of main messages, 3-page summary, full report) | Graded entry. Page counts are house style | core |
| ODI brief checklist (purpose early, argument, sources shown, fits context, actionable, plain language) | Checklist | core |
| GRADE Evidence-to-Decision for health systems (priority, effects, economic impact, equity, acceptability, feasibility, monitoring) | A compact table per option | core |
| Budget impact analysis (ISPOR) | Any "release money" decision | core |
| RE-AIM (reach, effectiveness, adoption, implementation, maintenance) | Monitoring in action plans. Pick the dimensions that matter | core for action plans |
| Adaptive pathways (signposts and triggers) | Plans under uncertainty, such as forecasts and outbreaks. Use the trigger rule only | core (rule only) |
| GRADE informative statements | Wording of certainty | core |
| WHO-INTEGRATE | Prompt list for national or rights-sensitive briefs | optional |
| CFIR | Four or five barriers inside the implementation section | optional |
| CHEERS 2022 | Only when an economic evaluation is in the document. Items on perspective, time horizon, discount rate, price date, uncertainty guide the basis label | optional |
| Theory of change or logframe | Half-page results chain in action plans | optional |
| Bardach eightfold path | Internal checklist for the options section. Step details not verified | optional |
| IPCC uncertainty guidance | Only when probability words appear. Give numbers beside the words | optional |
| UK inverted pyramid | Supports the ask-first rule | optional |

## Compact option table (GRADE EtD style, house layout)

Use one table per option. With three or fewer options you may use one combined table, with the options as columns. Rows:

| Row | Content |
|---|---|
| What it is | One line |
| Benefits | Effect with number, range and certainty rung |
| Harms | Same |
| Cost | Yearly, with basis label |
| Equity | Who gains and who may be left out |
| Acceptability | Who agrees, who resists |
| Feasibility | What must be in place |
| Monitoring | Signpost, trigger |

Print a key for the certainty rungs under the table. See `claims-and-numbers.md`.

## Recommendation rule

EVIPNet says never include recommendations. CHSRF, ODI and the Cabinet note format ask for implications or an approval ask. Resolution: include one recommendation, labelled as opinion, apart from the evidence, with its strongest reason and its least certain part. It is not stronger than the finding. This is a design choice, supported by stated preference and one intent trial.
